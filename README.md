# Mashru
Mantoq to mafhoum

محرّك عربيّ مبرهن: **الدال وحده ← المدلول وحده ← الدال والمدلول معًا ← العقلية ← الجواب**.
كلّ ادّعاء في الجواب منسوبٌ إلى قاعدةٍ واحدة لها إصدار وشاهدٍ مودَعٍ مختوم، ويعيد فحصَه الفاحص نفسه.

## قدرات NABT المثبّتة داخل Mashru

مرجع التحديث الحالي هو NABT **`0.16.0a1`** عند الإيداع
`d791fd7730cde2256dfac8a27687010b392876b3`، بعد
[PR #17 في NABT](https://github.com/sonaiso/NABT/pull/17).
سبقه [دمج المرحلة الأولى في Mashru، PR #75](https://github.com/Saleh1967/Mashru/pull/75)
عند `2bb5b1c262ab66ca5b5c12f4cf6bf20b63960cde`، بمصدر NABT
`f0064f0a4baab3cc816087a322aabc0c8fbb2d19` بعد الطلبين #15 و#16.
مرجع نتيجة [هذه المتابعة](tahaqquq/nabt_evidence/current_validation.json)
هو سجل التحقق المحلي بهوية مصدره، مع حفظ سجل المرحلة الأولى.

تتضمّن الطبقة تشغيل NABT وبراهينه محليًا.
تشمل الجبر المتدرّج من الجذر إلى التركيب، وربط المصدر بالشاهد، والبحث العقلي،
والقوانين المحدودة المسندة إلى المصادر العربية. يربط `Jisr/Nabt.lean` هذه
الطبقة بتعريفات Mashru الفعلية مع حفظ أبجدية الخلية وحدود المصدر ومرتبة الدليل.

يوسع الإصدار الجديد تركيب الإضافة والنعت وشبه الجملة والحال والزمن، ويحفظ
بدائل القراءة التي تحتاج مقدمات إضافية. ويشترط عقد الجواب
`nabt.discourse-answer.v2` اتفاق نتائج جميع قراءات السؤال الكاملة في التقرير؛ قد تكون
`query=null` مع حفظ الاستعلامات في `question_interpretations`، ويبقى اختلاف
النتائج أو وجود قراءة معتبرة غير مكتملة سببًا للتأجيل.

اجتازت [الجولة المحلية الكاملة في Mashru](tahaqquq/nabt_evidence/pr17_full_v1/manifest.json)
خطواتها الـ11 بالرمز 0: **1368 اختبارًا رئيسيًا لـNABT** و**67 اختبارًا
للتكامل المحلي**، بلا تخطٍّ، مع **990 تصريحًا مدققًا في المصدر المستورد**.
أعادت الجولة قياس **80/86 للتركيبات** و**63/86 للخطاب**، مع
`strict_pass=false` فيهما. تضيف `ArabicCoverage` ثماني
مبرهنات عامة مشروطة على السلامة والاكتمال وحدود العينة وحفظ القراءات،
ولا تثبت أن التنفيذ اكتسب العربية كلها. تفصيل المقاييس وحدودها في وثيقة الربط.

محليًا، خرجت [البوابة الأصلية دون مسح الطفرات](tahaqquq/nabt_evidence/pr17_development/native_gate_receipt.json)
بالرمز 0: تدقيق 1579 تصريحًا بلا مسلمات خارج المسموح، وسجل 530 طفرة سليم
يحفظ الطفرات الـ527 السابقة، وسجل الضبط ببنوده الـ45 محفوظ.
[قُتلت الطفرات الثلاث الجديدة 3/3](tahaqquq/nabt_evidence/pr17_development/new_mutations.log)
في فحصها المحلي؛ واجتياز مسح الطفرات الـ530 كاملًا على CI لإيداع الطلب
نفسه **شرط الدمج**.

```bash
lake build
./.lake/build/bin/nabtBridge
python3 -I scripts/nabt.py runtime analyse 'كَتَبَ'
python3 -I scripts/nabt.py classical audit
python3 -I scripts/nabt.py recursive --help
python3 -I scripts/check_nabt.py --help
```

كلّ تشغيل عبر `scripts/nabt.py` يتحقّق أولًا من هوية المصدر المحلي المثبّت.
التفاصيل وحدود البرهان وأوامر إعادة الفحص في
[ربط Mashru بأحدث NABT](hawkama/NABT_ALIGNMENT.md).
القارئ `qari` والفاحص `faahis` يحتفظان بعقديهما؛ وتعرض واجهة NABT قدراتها
بأسمائها ونطاقاتها. لا تنتقل نتيجة هذه الواجهة إلى مرتبة «مفهوم» دون شاهد
الواقع المختوم الذي تتطلبه مراتب Mashru.
