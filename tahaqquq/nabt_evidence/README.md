# أدلة محاذاة NABT الحالية

التشغيل الكامل الحالي هو `full_v2/manifest.json`: انتهى بنجاح في2026-10-24، من النسخة ذات598 ملفًا والقفل المثبت المذكور فيه. حُفظت سجلات مراحله العشر، مع تقارير التدقيق والبحث والشواهد والجبر الراجع والتراكيب والخطاب. يحصي البيان بصمات التقارير الـ48 الناتجة، وقد طابقت جميعها الملفات الفعلية؛ التقارير المختارة هنا محفوظة للمراجعة، وتحتفظ بوابة GitHub بمجلد التشغيل الكامل في مرفقاتها. المسارات المطلقة داخل السجلات هي مسارات تشغيل الجلسة، وليست اعتمادًا على تلك الآلة.

ظهر سجل المرحلة04 بعد انتهاء العملية ناقص السطر الأخير، رغم اكتمال التشغيل وسجل نتيجته. حُفظت النسخة المرصودة في `observed_upstream_build_partial.log`. أُعيد أمر البناء منفردًا بنجاح؛ خرج ببايتات تطابق تمامًا بصمة السجل الأصلي التي سجلها المنفذ قبل الانتقال إلى المرحلة05. استُعيد `full_v2/04-upstream-build.log` من تلك الإعادة المطابقة، وبقي البيان الأصلي كما هو. تفاصيل ذلك في `current_validation.json`؛ سبب مزامنة الملفات استنتاج، وليس حقيقة مثبتة. صارت بصمات السجلات العشرة المحفوظة مطابقة للبيان.

يلخص `current_validation.json` الفحوص المحلية ويميزها من تشغيل527 طفرة الكامل المطلوب على CI. تمت إعادة بوابة Mashru محليًا دون الطفرات القديمة، ثم قتل الطفرات الثماني الجديدة بمنفذها الأصلي. يذكر سجل البوابة صراحة الاختبارات المعتمدة على مودعات غائبة. رُفع خط الأساس من1538 إلى1579 بعد هذا التحقق.

حُفظ `failed_full_v1.json` وسجله والقفل الأول (`initial_snapshot.lock.json`) لأنه كشف نقص بيانات إعادة الفحص. يسجل `replay_fixture_completion.json` القطع الاثنتي عشرة المستكملة من المصدر المثبت نفسه؛ لم تُعدَّل توقعات الاختبار أو شفرة NABT. يحفظ `DEVELOPMENT_NOTES.json` كذلك إخفاق الموارد الأول وتصحيحات حراسة Python ومنفذ التحقق.

النتائج المنتهية لا تعني اكتساب العربية أو اكتمال تغطيتها. للمعنى الدقيق والحدود راجع `../../hawkama/NABT_ALIGNMENT.md` وتقارير التشغيل الأصلية.
